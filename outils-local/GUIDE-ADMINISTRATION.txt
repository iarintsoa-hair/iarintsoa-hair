IARINTSOA Hair - Gérer la boutique depuis l'administration
==========================================================

ADRESSE : https://iarintsoa-hair.netlify.app/admin/
(fonctionne une fois la mise en route ci-dessous terminée)


A. UTILISATION AU QUOTIDIEN
---------------------------
1. Ouvrir l'adresse /admin/ sur l'ordinateur, cliquer « Se connecter avec Netlify Identity » (e-mail + mot de passe).
2. Cliquer « Boutique » puis « Mes perruques ».
3. AJOUTER une perruque : bouton « Ajouter perruque » en bas de la liste.
   - Remplir le nom, la description, la texture, les longueurs et les prix.
   - Laisser « Adresse de la fiche » VIDE : elle est créée à partir du nom.
   - Photos : « Ajouter photo » puis « Choisir une image » > « Téléverser ».
     La première photo est la photo principale.
4. MODIFIER : cliquer sur la perruque, changer ce qu'il faut.
5. MASQUER (sans supprimer) : cocher « Masquer du site ».
6. SUPPRIMER : icône « X » à droite du nom de la perruque.
7. Cliquer « Publier » (en haut) puis « Publier maintenant ».
   Le site se met à jour tout seul en 1 à 2 minutes :
   accueil, boutique, recherche, fiche, panier, commande WhatsApp.

Conseils
- « New » dans Étiquettes = la perruque apparaît dans « Nouveautés ».
- Prix différent selon la longueur : remplir le prix sur chaque ligne de longueur.
- Une perruque incomplète (sans photo par exemple) n'est pas affichée : rien ne casse.
- Tout est historisé dans GitHub : une erreur peut toujours être annulée.


B. MISE EN ROUTE (une seule fois, sur Netlify)
----------------------------------------------
Connexion par e-mail + mot de passe (Netlify Identity + Git Gateway).
Aucune application OAuth à créer.
1. Projet iarintsoa-hair > Project configuration > Build & deploy >
   Link repository > GitHub > iarintsoa-hair/iarintsoa-hair (branche main).
2. Project configuration > Identity > Enable Identity.
3. Identity > Registration : choisir « Invite only » (sur invitation).
4. Identity > Services > Git Gateway > Enable Git Gateway.
5. Onglet Identity (en haut) > Invite users > votre e-mail.
6. Ouvrir l'e-mail reçu, cliquer le lien, choisir un mot de passe.
7. Se connecter sur https://iarintsoa-hair.netlify.app/admin/

Sécurité : inscription « sur invitation » uniquement ; seules les personnes
invitées peuvent modifier la boutique.
